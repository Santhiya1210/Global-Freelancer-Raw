 # Global-Freelancer-Raw

# Overview

A short summary of the dataset global freelancer raw which contains raw freelancer information such as skills, pricing, categories, and basic profile details.

# File Description

Global freelancer raw Main raw dataset with freelancer-related data for analysis, cleaning, and visualization.

# Data Set
  Freelancer Profile : ID, Name, Gender, Age, Country.
  Skill Information  : Primary Skill, Years of Experience.
  Performance : Rating, Client Satisfaction, Active/Inactive Status.
  Finacial Data : Hourly Rate(USD)
  Work History : No.Of.Project , Duration, Status.
